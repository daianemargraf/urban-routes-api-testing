# Urban Routes – API Testing Project

This project focuses on REST API testing practices applied to the Urban Routes application.

The project demonstrates API endpoint validation, request and response analysis, status code verification, JSON validation, positive and negative testing scenarios, and bug reporting using structured QA documentation techniques.

---

# Project Scope

The project was designed to validate the functionality, reliability, and behavior of API endpoints used in the Urban Routes application.

Testing activities included:

- REST API Testing
- Endpoint Validation
- Request Validation
- Response Validation
- JSON Validation
- Status Code Verification
- Positive Testing
- Negative Testing
- Bug Reporting

---

# QA Activities Performed

- Executed API requests using POST methods
- Validated API endpoint behavior
- Verified HTTP status codes
- Analyzed JSON request and response bodies
- Tested positive and negative scenarios
- Validated API business rules
- Identified unexpected API behavior
- Documented defects and inconsistencies
- Linked bug reports using JIRA
